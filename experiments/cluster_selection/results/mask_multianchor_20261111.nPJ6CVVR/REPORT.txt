Checkpoint: epoch_0025.pt; trained weights unchanged. All 55 frozen validation puzzles, including 8 ordinary-GAC solutions.
One CPU thread, one process, sequential randomized/interleaved methods. All 660 solves valid. Nodes 10000; seconds 300 guard.
Learned cluster allowance 64 total per propagation episode; top K anchors decoded together and duplicates removed.
After pruning, discard the remaining proposals and recompute from updated domains; after no-op, try the next anchor.

Scope and limitations:
The same 55 validation puzzles were used for checkpoint selection and this comparison; no final test evaluation.
Comparable aggregate observed CPU wall time; no exact per-puzzle deadline or fixed episode time budget.
Extra anchors decode existing weights without retraining; proposals are deduplicated and refreshed after pruning.
All learned variants retain allowance 64 total contractions per closure episode; heuristic caps16/32/64 are separate methods.
Timings include state setup, inference and solving but exclude checkpoint loading, warmup, result serialization and code hash checks.
Heuristic 16 dominates all tested learned variants by both total time and DFS nodes in the full sweep.
