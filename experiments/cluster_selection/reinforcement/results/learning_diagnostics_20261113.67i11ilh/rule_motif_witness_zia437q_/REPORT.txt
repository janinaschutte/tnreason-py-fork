VERIFIED RULE-INSPIRED GENERIC HEURISTIC WITNESSES

Concrete Sudoku example: a naked triple in row 1, columns 1, 4 and 7,
with domains {1,2}, {2,3}, {1,3}. Ordinary GAC stalls. These three cells
must collectively use digits 1,2,3, so those digits can be removed from the
other cells in that row. This is an illustrative constructed domain state,
not an additional held-out Sudoku solve.

Checked through the existing generic joint-summary executor:
  18 original link cores, retaining three row-digit category variables;
  estimated work 2,916, maximum 729 tensor entries;
  contraction plus GAC removes 90 domain values including auxiliaries.
The original closed state is restored after every independent trial.

Frozen old heuristic, same full 9x9 network:
  cycle cap 8, 512 proposals, 131,072 search steps, core cap 64,
  at most 6 outputs, work <=1e6 and tensor size <=1e5;
  generated 512 candidates, contracted all 512, found ZERO useful candidates.
On the isolated original triple region, it generates no cycle-8 candidates.
Raising its cycle cap to 12 gives one useful proposal. This is a measured
coverage gap under the stated bounds, not a claim that every larger search
budget or every structural extension must miss the deduction.

Independent generic witnesses use no Sudoku variable names or geometry:
  Xi (i=0,1,2) has dimension 3; Yj (j=0,1,2) has dimension 4.
  Each Boolean Bij is linked by original tensors to Xi=j and Yj=i.
  Yj value 3 denotes an outside alternative. Boolean truth labels are
  consistently flipped on alternating indicators, so their actual supports
  matter. All 18 original cores and domains are in generic_variant.json.
