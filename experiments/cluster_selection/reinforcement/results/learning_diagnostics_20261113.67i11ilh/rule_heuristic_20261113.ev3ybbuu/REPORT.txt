OPTIONAL GENERIC RULE-INSPIRED HEURISTIC: PAIRED SOLVING RESULTS

Implemented in the optional rule_heuristic module: recognize category/Boolean channels from original realized tensor support, then propose overlap and small Hall (2--4 source) clusters. Names, Sudoku coordinates and global digit labels are not used. The original cores remain authoritative; only conditioned contraction and GAC prune domains. The default attachment path and all existing training/GPU sources remain unchanged. This generalizes two structural ideas, not all 51 expert families.

The optional extension saves one DFS node and adds one solve without branching (position 13). The other 15 puzzle node counts are identical to the refreshed cycle8 control. This is a modest improvement on a small reused set, not evidence that the generic solver now matches the expert. Raising the cycle cap alone to 12 performed worse under the same finite search budget; it redistributes search across lengths and changes proposal coverage, so this does not show that longer cycles are inherently worse.

Actual new root solve: in puzzle 13, digits 1,3,6 in column 3 are confined to rows 2,7,8. The generic support graph detects this hidden-triple structure. Two 12-core Hall contractions, with one 4-core overlap contraction between them, remove 15,15,309 domain values including auxiliaries and solve the root. The cycle8 control needs one branch. All three contractions were independently rederived from their saved domains.
