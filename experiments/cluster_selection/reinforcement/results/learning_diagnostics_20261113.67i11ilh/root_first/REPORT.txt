Root-only saturation diagnostic (16 reused Sudoku puzzles)

Goal: solve by propagation only, rather than share a small cluster allowance fairly.
No domain assumptions, assignments or DFS were used. Original ConstraintNetwork
cores remain the representation; each domain-conditioned contraction adds one
temporary summary, GAC retains its pruning, then the summary is removed.

  Method                         Solved without DFS   Post-GAC root-only time
  All generic sources combined   14/16                955.77s
  Sudoku expert, 51 families      15/16                 13.57s

  The initial teacher-first phase already solved all14 generic successes;

The new generic root solve is puzzle position12: the unchanged teacher required
272 contraction attempts and10 useful clusters. This is more inference search,
not a new trained checkpoint. Later RF suggestions did prune4 more primary cell
values across the two remaining puzzles, and a later teacher cluster pruned1,
but neither puzzle became solved. The masks, structural proposals, replay model
and Q model added no pruning in their later phases on these remaining states.

Stopping rules (frozen before querying)
  Teacher first; then heuristic, mask, teacher, original RF, replay RF and Q.
  Rotate source after128 consecutive actual no-op contractions, or decoder
  exhaustion. Reset this streak after any domain removal, including auxiliaries.
  Repeat complete source sweeps while any domain shrinks. Stop after a complete
  six-source sweep without new information, a solution/contradiction, or600s.
  Teacher-first1024 and later512 contraction limits are emergency rotation guards.
  Decoder steps262144 initially,131072 per later source, refreshed after pruning.
  Structural lists keep32 proposal breadth; mask considers32 anchors.
  Each cluster: <=64 original cores, <=6 outputs, work<=1e6, tensor size<=1e5,
  compact current domains. No cumulative tensor-work cap.

The remaining cases stopped naturally, without reaching the600s guard:

  position8: third full sweep stalled;432.47s;50 primary cells still unfixed.
These are stalls under the searched decoders and stopping rules, not proofs that
no useful cluster exists.
