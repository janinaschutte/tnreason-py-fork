What was held fixed
All four arms start from exactly the same parent weights with fresh Adam, learning rate0.0003, seed29, the same frozen state/update order, and exactly240 gradient updates (10 visits to each of24 states). No validation-dependent early stopping or model selection. Complete measured positive teacher pools are used; no top-eight truncation. Nested uniform and both quality arms share the same nested pool. Direct/nested share80 failed-value probes, but mutations depend on the pool, so direct/nested is not a pure structural-cap or strict-superset ablation.
All learned solves use discrepancy decoding, allowance32 per propagation episode, max64 cores, six outputs, estimated contraction work1,000,000 and tensor size100,000 per cluster, and no cumulative work cap. Decoder/heuristic search caps are8,192 operations of different kinds, not matched CPU work. No timing advantage is claimed. Temporary summaries, retained pruning, and backtracking behavior are unchanged.

Teacher evidence
All24 states have positive measured teachers in both pools. Direct structural search produced43.96 proposals per state on average; nested produced256. Positive pools contain1,488 and1,580 teachers. Best measured pruning reward is identical between pools on every state. The90% quality threshold retains266 nested teachers (11.08/state); these are verified under original domains by contraction and GAC. Reward1 includes both completed solutions and contradiction proofs on branch states; it does not mean every such example solves the original puzzle.
Uniform teacher sampling credits weaker positive teachers equally in the original imitation objective. Quality filtering removes them before trace sampling and compatible-action targets. The greedy variant also changes the loss and prefix trajectory. Absolute losses across these different objectives are not quality comparisons.

Free-construction fitting check
Each training state has a known useful teacher, yet free greedy usefulness is1/24 for the parent and both unfiltered arms,0/24 for filtered mass, and4/24 for filtered greedy. All four filtered-greedy successes are on the11 branch states; none is on the13 roots. Every reported greedy count uses one unforced construction and contraction/GAC. It is distinct from full solving with discrepancy search over multiple proposals.
This shows poor fitting after240 updates, not proof of convergence or that more training/data cannot help. A read-only complexity audit found that shortest near-best teachers would average21.38 construction decisions, versus32.48 when averaging the complete near-best pool per state. No such simplified-teacher training was run.

Next diagnostic

If training usefulness rises,240 updates were insufficient; if training fitting becomes strong but unseen usefulness remains weak, focus on data/state coverage.
